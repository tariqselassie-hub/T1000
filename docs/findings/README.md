## Experimental Standards & Verification Criteria

1. **Hardware-Grounded Telemetry:** All latency, memory throughput, and execution cycles are measured via hardware high-resolution timers (`std::time::Instant`, RDTSC, or UART hardware cycle counters).
2. **Reproducibility:** Every empirical table corresponds directly to a compiled binary in `crates/t1000/src/bin/` with documented deterministic PRNG seeds (`DEFAULT_SEED = 0x5EED_0042`).
3. **Norm & Unitarity Invariants:** Unitary evolutions preserve the $\ell_2$ norm to within floating-point epsilon ($|\|\psi\|^2 - 1.0| < 10^{-12}$).
4. **Boundary Condition Rigor:** Physical boundary conditions at $t=0$ are formally anchored to known pure eigenstates ($\langle Z_0 \rangle = +1.0, S_0 = 0.0$).
