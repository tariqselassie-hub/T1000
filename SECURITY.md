# Security Policy

## Supported Versions

Security updates and critical patches are actively applied to the following release branches:

| Version | Supported          |
| :------ | :----------------- |
| `0.1.x` (master) | Yes |

---

## Reporting a Vulnerability

If you discover a potential security issue, unauthorized memory safety violation, or algorithmic vulnerability within the T-1000 codebase, please report it privately:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the project maintainer: `tariqselassie@gmail.com` (or submit a Private Vulnerability Advisory via GitHub Security Advisories).
3. Include in your report:
   - A detailed description of the vulnerability.
   - Minimal reproduction code, test vector, or script.
   - Potential impact on quantum simulation state registers, telemetry streams, or host systems.
   - Any proposed remediation or patches.

### Response Timeline
- **Initial Triage:** Within 48 hours of receipt.
- **Remediation Assessment:** Within 7 business days.
- **Coordinated Disclosure:** A CVE and advisory will be published once the patch is merged and validated across supported environments.
